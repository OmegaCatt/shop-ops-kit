Fiktivní ukázka. Produkty, objednávky i zásilky jsou připravená testovací data. Nástroj nečte žádná firemní data.

Jak fungují obě kontroly Technologie, vstupy a pravidla

Technologie: HTML, CSS, JavaScript a místní Node.js server. Nástroj nepoužívá externí API ani API klíč.

Katalog: CSV se zpracuje v prohlížeči; pravidla kontrolují SKU, trh, měnu, cenu, sklad a cestu produktu. Volitelný předchozí CSV export umožní porovnat změny.

Objednávky: Fiktivní události zásilek se párují s objednávkami; stejná událost se započte jen jednou. Nálezy ukazují řádek nebo ID události. Rozhodnutí o opravě zůstává na člověku.

VSTUPNÍ DATA

Produktový export

JSON: verze 1, pole products se sedmi textovými poli katalogu. Zdroj je označen cestou products[index]. Stejná pravidla a schvalování jako CSV.

PŘED PUBLIKACÍ

Schválení změn

Prověření nálezu není schválení změny. Důležitý nález blokuje schválení; upozornění vyžaduje důvod a výjimku do 30 dnů. Rozhodnutí platí jen pro oba aktuální soubory a pravidla. Jde o místní ukázku bez ověření identity; nic se nezapisuje do e-shopu.
